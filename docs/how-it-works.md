# 原理

[Make Me a Hanzi](https://github.com/skishore/makemeahanzi)（MMAH）记录了每个字怎么拆、每一笔属于哪个部件，但它的笔画几何来自一套楷体。paoding 把这些笔画配准到目标字形上，再据此切分目标字体自己的轮廓（或像素）。MMAH 的几何只用作参照，不写进产物。

## 1. 参照

MMAH 给出拆法、每一笔所属部件的路径，以及笔画轮廓和中线。更深的层级里，部件按它们自己的条目继续展开。

MMAH 没有的字（《通用规范汉字表》里约 1200 个，多为三级字）由部件拼成参照：

- 按 BabelStone 的 IDS 表拆开；
- 每个部件的笔画取自 MMAH 里在同一位置有这个部件的字：玕 `⿰𤣩干` 的 𤣩 取自 玩 的左边，干 取自 刊 的右边，所以部件保持它在这个位置上的样子；
- 并排的部件来源不同，互相重叠或离得太远时，把交界移到中间；
- MMAH 和 IDS 表对同一部件的叫法不同时（汤：`⿰氵昜` 与 `⿰氵𠃓`），两种叫法都能找到它。

拼出的参照只是近似，靠配准贴到目标字形上。这些字的记录带 `"composed": true`。IDS 中有未编码部件等、找不到笔画的字不拼。

## 2. 配准

先把参照的墨迹外框对齐到目标的外框，再用平滑的非刚性形变把中线拉到目标的骨架上，按位置和笔画方向匹配，由粗到细。

之后逐层把每个部件单独再配准一次：先对它覆盖的墨迹做仿射拟合，再做一次更温和的形变。部件保持自身形状，笔画不会被拖到邻近部件的墨迹上。

## 3. 归属

目标字形的墨迹分成若干单元：一条外轮廓连同它的孔洞。

- 只有一个部件的中线穿过的单元，整个归这个部件；否则沿配准后笔画周围的条带切开。
- 一笔只能在一个单元里。中线主体在一个单元、只有一小段伸进另一个单元时（楷体的笔画末端常常更长），这一段不算。
- 部件相交处的面是共有的。拍平视图把它交给穿过交接处的那一笔，交叉时交给叠放在上层的部件。

位图字体逐个像素归属，并把被打断的横竖像素串修补回同一个部件。

## 4. 评分

对每个部件，看它的中线有多少落在自己的墨迹上，以及它的墨迹有多少明显更靠近别的部件的笔画（位图字体看像素串有多少被别的部件截断）。置信度取最弱的部件，低于阈值的字标为 `low`。

## 5. 结构检查

矢量字体。参照是楷体，笔画的长短和比例与目标不同，配准偏了，切线就可能落在一笔的中间。所以再用目标字形自己的结构核对一遍：

- 把墨迹的骨架在交点、拐角和收腰（两笔首尾相碰处）断开，其间的一段是一笔，应当只归一个部件；
- 一个部件的叠加墨迹不该孤零零地伸进别的部件的笔画里。

不符的位置记在 `flags` 里，并降低置信度。

## 6. 字体自身的部件

矢量字体。同一字体里，同一部件几乎每次都画得一样。`run` 先跑一遍，从有把握的字（`auto` 且无结构标记）里收集两样东西，再重跑用得上的字。

**整块单元**：独立成块的部件（阝、氵、口）。某个被切开的单元，若和至少两个字里它的主要部件的整块单元同形同大，就整个交给这个部件。

**模板**：与别的部件相接的部件（誠 的言、等 的⺮）不成独立的单元，但字体常在别的字里把它画成独立的样子。对有结构标记或低置信的字，把这些模板放到本字墨迹上对齐（小幅平移和缩放）。模板几乎整个落在墨迹上、不占别的部件的整块单元、又容得下这个部件的大部分参照中线时，它盖住的墨迹归这个部件。

两种情况下，落到不属于自己的墨迹上的参照中线都视为配准拉偏，不再计入评分和结构检查。拼合参照的字使用这些收集，但不往里添加。`inspect --run` 沿用运行记录里的结果。
